# Historial de bugs y parches (SUNO_server)

Registro hacia atrás de defectos corregidos, reconstruido el 2026-11-17 a partir de `git log` (commits `fix:` y «Corrige…»), las secciones «Corregido» de [`CHANGELOG.md`](../../CHANGELOG.md) y las correcciones de revisión anotadas en [`plans/suno-progreso.md`](../../plans/suno-progreso.md). Desde ahora cada corrección nueva se registra aquí en su propio PR ([`CONTRIBUTING.md`](../../CONTRIBUTING.md#bugs-y-parches)).

- **Versión:** la primera release que incluye el parche. «—» si no hubo release (antes de v0.1.0 o aún sin integrar).
- **Prueba de regresión:** ruta actual de la prueba que falla sin el parche. «—» si no hay una identificable; no se inventó ninguna. Las rutas antiguas `server/visitacampo/…` hoy son `server/suno/…`.
- **Defectos de revisión:** los encontrados en la revisión de un PR antes de integrarse se listan aparte (sección 2) porque nunca llegaron a `master`.
- Los fallos de la app de la época del monorepo están en el historial de SUNO_client.
